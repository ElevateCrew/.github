# Elevate
Take full control of your Emergency Response: Liberty County server with Elevate. Featuring deep integration with the ER:LC API, Elevate delivers real-time server status updates, comprehensive logging (joins, kills, and commands), staff oversight, and remote in-game management tools directly to your Discord community for effortless administration.
